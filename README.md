One Word, One Username, One Reward — **hazel-lynx-59**, the entrant's own make.fun username. A deterministic Python 3 program (standard library only, no network) that writes exactly one word, the handle `hazel-lynx-59`, to `/output/entry.txt`. No explanation, no links, no pitch — the judge's first criterion is that the entry is a real make.fun username, the entrant's own handle sent as one word, and anything else loses to any genuine handle.

## Run it

```sh
python3 main.py
```

The program writes 13 bytes, `hazel-lynx-59`, to `/output/entry.txt` — no newline, no extra text. The output is byte-identical on every run.
